# Окно индикаторов по выбранному образцу

21.11.2026 — следующий этап оформления Stock Monitor 0.16 TEST. Главное окно уже опубликовано отдельно. На этом этапе изменяется только окно индикаторов.

Оформление: тёмный фон, голубые контуры и отмеченные переключатели, более крупные подписи, две колонки параметров, порядок полей из выбранного изображения, справочная карточка снизу и постоянно видимые округлённые кнопки «По умолчанию» / «Применить». Нативный тёмный заголовок сохраняет обычные действия Windows. Прокрутка колесом ограничена этим окном; переход Tab раскрывает скрытое поле. Минимум 500×500, размер подстраивается под экран. Поддерживаются прежние светлая и контрастная темы.

Сохранён прежний apply-handler Desktop014: сравнение исходных настроек с текущими, отказ во время записи из чата, существующая validate и прежний set_setting/refresh. AST тела обработчика совпадает с исходником до оформления. Формулы CORE, стратегия, CandlePilot, Bridge/MCP-команды, счёт и позиции не изменены. Кнопка сброса меняет только черновик до «Применить».

Четыре целевых теста PASS за 4,866 с: введённый период/переключатель проходят в прежний apply при сохранении остальных значений; недопустимый MACD/параллельная запись/изменившиеся настройки отклоняются; сброс без применения не сохраняется; при 500×500 кнопки видны, последнее поле раскрывается; стили всех трёх тем изолированы и повторно используются. Реальные счета в тестах не открываются.

Приёмка установленного Windows и проверка сохранности после запуска записываются после завершения. Основные торговые тесты и готовые аудиты повторно не запускались. Снимки счёта и приватная SQLite не публикуются.

Откат: вернуть только метод show_indicators из адресного исходника before indicator design и удалить подключение нового представления. Текущую базу не заменять. Параллельные изменения других задач не публикуются в этом этапе.

Оставшиеся этапы выбранного оформления: список акций, поиск/добавление, новости и рисование. Премаркет и экономический календарь главного экрана пока не имеют подключённого источника, поэтому значения с иллюстрации не подставлены. Настройка нового финансового источника не выполнена под видом смены дизайна.
