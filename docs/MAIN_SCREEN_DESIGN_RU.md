# Главный экран по выбранному макету Amazon

20.11.2026, Stock Monitor 0.16 TEST. Только оформление главного экрана. Этот этап заменяет отклонённый упрощённый вариант. Остальные выбранные окна — следующие этапы. Пиксельное равенство с растровым концептом не заявляется: действующий экран использует реальные данные, все 11 ТФ и существующие дополнительные функции.

## Области экрана

1. Тёмный нативный заголовок с логотипом, тонкая строка восьми меню, действующий CandlePilot, синхронизация загруженного графика, дата/часы Берлина с секундами. Все прежние команды сохранены. Синхронизация экрана не означает свежесть цены исполнения.
2. Боковой список: страны, индексы, коллекции, количество, поиск, логотипы, тикер/цена, красное/зелёное изменение, избранное. Коллекции фильтруют известные имена, не меняя очередь CP/universe. Избранное сохраняет только новый ui_favorites.
3. Шапка акции: логотип, имя, identity, цена EUR, изменение и объём выбранного TF. Вкладки, все 11 TF, режимы графика, индикаторы, рисование, линейка, сброс, PNG, настройки/fullscreen. В узком окне элементы переносятся, период остаётся доступен.
4. Цены справа и цветные метки последней цены/уровней. EMA fast оранжевая, slow голубая; объём, голубой RSI, MACD, фиолетовый ATR. Сохранены Volume Profile, рисунки, живая свеча, масштаб, периоды индикаторов. Подписи используют действительно нарисованные линии. CORE по-прежнему использует свои закрытые входы.
5. Правая область: действующий сигнал/причина, контекст TF, сегментная сила с фактическим процентом, условия, управление видимостью уровней, происхождение ряда и постоянно видимая шкала DQ. Прежние подробности/Benchmark доступны при прокрутке.
6. Общая нижняя строка 55/45: сохранённые новости и календарь. При смене ISIN прежняя лента немедленно очищается, чужой поздний ответ отклоняется.
7. Подвал: состояние, связь, штатная оценка PAPER-портфеля. Дневной результат при отсутствии исходного поля — «—», накопленный результат не назван дневным.

## Данные и ограничения соответствия

Числа, BUY, новости, премаркет, календарные события и «источник 0 минут» на образце не являются рабочими данными. Сила показывается только из принятого результата; соседние TF показывают фактический режим тренда без выдуманного BUY. DQ-шкала показывает категориальный статус: достоверного общего процента нет, поэтому 98% не подставлен. Премаркет/экономический календарь не подключены и явно отсутствуют. Неизвестные цены/логотипы не синтезируются. Количество акций соответствует текущему списку. LSEG и financial.com описывают один выбранный конвейер, не два независимых подтверждения. Архивная котировка слева не становится ценой исполнения.

Показ условий справа — факты закрытого CORE; значения графика могут включать живую свечу и пользовательские периоды. Торговые формулы, разрешения и счёт не изменены. Наличие существующего предупреждения данных не скрывается ради сходства с рисунком.

## Производительность и сохранность

Индексированное read-only чтение двух последних 15m по точному GETTEX/EUR receipt, без декодирования архивов/скачивания. Одно измерение TEST: 57 котировок из 65 инструментов за 0,0526 с. Неизвестные identity пропущены. Логотипы, новости, PAPER status и PNG используют существующий Dispatcher без новых потоков или торгового конвейера. Чтение счёта раз в минуту не создаёт заявки.

Видимость уровней использует прежний CAS: отказ при несохранённых локальных изменениях/параллельной записи. Меняется только настройка отображения. Сохранены темы, Bridge, PAPER, CP и callbacks.
