# СМ: рабочая область будущих задач

25.11.2026. Статус: способ установлен по официальной документации; фактическая проверка отдельной задачи НЕ выполнена.

В текущем чате cwd и writable_roots относятся к старой папке чата. Указание workdir команды не добавляет другую папку в разрешённые корни. Разрешение владельца описывает авторизацию; рабочую границу задаёт приложение. Для применения PR25 выполнены штатные адресные escalation с явным назначением — это не исправление рабочей области будущих задач.

## Шаг владельца в приложении

1. «Add new project / Добавить проект» либо Ctrl+O. Выбрать существующую папку `%USERPROFILE%/Documents/Codex/СМ/Рабочая версия 0.16`; не папку старого чата, не весь диск и не Store0.15.
2. Создать новый чат внутри этого локального проекта, режим Local. Worktree не нужен.
3. В управлении разрешениями под полем сообщения оставить профиль с записью только в рабочую область: Ask for approval либо Approve for me при доступном workspace-write. Full access не требуется. Если управляемая политика не даёт выбрать нужный профиль, это должен изменить владелец разрешений/администратор; AGENTS.md и текстовое согласие не заменяют профиль. По текущим данным необходимость администратора не доказана.
4. В первой задаче прочитать AGENTS.md, вывести cwd и эффективные writable_roots. В них должна быть именно папка проекта.

## Проверка в отдельной задаче

Поручить задаче без escalation и изменения профиля создать единственный новый файл `docs/.workspace-write-check.txt`, записать фиксированную неперсональную строку, прочитать обратно и удалить только этот созданный файл. При существующем одноимённом файле ничего не менять. Не обращаться к БД, настройкам, стратегиям, сделкам и работающему TEST. При отказе остановить пробу и показать точную причину. Успех адресного escalation в прежнем чате не засчитывать как успешную проверку новых корней.

В инвентаре list_projects этого сеанса возвращены только14 ChatGPT-проектов, локальный СМ отсутствует; create_thread требует существующий локальный projectId. Команды добавления локальной папки нет. Владелец разрешил выполнить действие самому; инструментальное ограничение осталось. Computer Use запрещает автоматизацию интерфейса ChatGPT, поэтому этот путь не использовался. Отдельная задача проекта не создана, никаких фиктивных PASS нет. После добавления проекта доступ можно проверить create_thread в Local с указанной узкой пробой.
