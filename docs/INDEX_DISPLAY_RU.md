# Индексы Stock Monitor 0.16 TEST

Все 11 ТФ доступны у шести прямых индексов: 5m, 10m, 15m, 30m, 1H, 2H, 3H, 4H, 1D, 1W, 1M. Внутридневные строятся из настоящего Yahoo 5m, дневные агрегаты используют прежний дневной источник. У VIX это отдельные Yahoo ^VIX 5m и Cboe VIX 1D; история разных поставщиков не склеивается.

Приёмка относится к доступности графиков. UNCONFIRMED/STALE, неполные агрегаты, недостаточный прогрев и ограничения источника сохраняются; показ истории не создаёт торговое разрешение. Данные счёта и стратегии этим этапом не изменялись.
