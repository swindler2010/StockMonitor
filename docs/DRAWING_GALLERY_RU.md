# Каталог рисования и избранные инструменты

Work1, 21.11.2026. Продолжение выбранного макета рисования.

Вместо единственной группы по умолчанию показывается прокручиваемый каталог всех
8 групп / 34 уже реализованных инструментов. Каждый раздел сворачивается.
Сохранён фильтр по одной группе. Слева быстрый доступ; сверху отдельная команда
редактирования избранного. До 12 инструментов, без создания рисунка при смене
звёздочки. Кнопка инструмента использует прежний guarded capture/commit.

Новая общая UI-настройка `ui_drawing_favorites`: чтение/запись через существующий
Dispatcher misc, без SQLite на Tk и новых потоков. Менеджер общий для открытых
панелей разных акций, редактирование сериализовано. При отказе очереди или записи
показана ошибка и ручной повтор, несохранённый список не выдаётся за сохранённый.
Неизвестные идентификаторы фильтруются, дубли удаляются, максимум 12.

Для небольших окон содержимое прокручивается отдельно; нижние действия, undo/redo
и Готово закреплены. Вкладки Инструменты/Объекты прокручивают к нужному блоку.
Разделы и новые сообщения локализованы ru/de/en; символы сворачивания ASCII,
чтобы избежать отсутствующих глифов системного шрифта.

Не изменены renderer, свечи/DQ, торговые разрешения, CORE, стратегии, счёт,
позиции, CP, Work2, Store 0.15, Performance Engine. Это организация существующих
инструментов, не завершение всей картинки. Ещё остаются отдельные виды разметки
из большого макета (спираль, угол, смещённый канал, проекции и декоративные метки),
а премаркет и числовая тональность требуют настоящего источника данных.

## Проверки

Новый сценарий Favorites: отложенное чтение/запись только собственного UI-ключа,
ошибка/повтор, отказ очереди/закрытие, валидация сохранённых данных, повторное
чтение из изолированной SQLite без изменения посторонних настроек.
Gallery: все группы, фильтр/сворачивание, сохранность черновика, доступность списка.
Повторены 7 затронутых тестов drawing_dialog (размеры, кнопки, guarded операции).
Промежуточный итог: 13 PASS / 223,040 с; длительность полного Tk-harness не является
измерением задержки клика рабочей программы. Финальный опубликованный прогон и
реальная Windows-приёмка дописываются ниже.

## Откат

Адресные before drawing gallery файлы и патч в СМ-Архив. Вернуть только собственный
изменённый drawing_dialog, удалить импорт нового gallery по патчу и свои ключи
перевода; не заменять всю грязную рабочую версию/SQLite. UI-ключ можно оставить:
старый код его не использует. Сохранённые рисунки используют прежний формат.
