# Окно поиска и добавления акции

21.11.2026 — Stock Monitor 0.16 TEST, следующий выбранный экран после главного, индикаторов и списка.

Тёмное окно с заголовком/подсказкой, поисковой строкой и очисткой, таблицей названия/тикера/ISIN/площадки/валюты/типа, двухколоночной формой из семи прежних полей и закреплёнными кнопками очистки/отмены/добавления. ISIN и остальные подтверждённые значения появляются в таблице только после существующего resolver. Поля, ещё не полученные от источника, обозначены прочерками. Никакие примерные строки NASDAQ/GETTEX с картинки не подставляются.

Прежние вложенные обработчики add и find совпадают по AST с исходником до оформления. Сохранены generation guard при смене строки/запроса, проверка запрошенного ISIN, подтверждённая identity, запрет редактированных symbol/venue/currency/history/profile, проверка дубликата и register_confirmed_instrument. Новая «Очистить» увеличивает тот же selection_generation, очищает черновик/таблицу и отключает добавление, поэтому запоздавший resolver не оживляет очищенный выбор. Нет нового пути допуска/торговли, изменения базы или самостоятельной загрузки при открытии окна.

Три целевых теста PASS 5,238 с: поля подтверждённой строки идут в прежнюю изолированную регистрацию; очистка отвергает поздний ответ; изменённая identity отклоняется. Используется макет приложения без рабочей базы/счёта и без сетевых запросов. Неподтверждённые строки не включают Add. Приёмка установленного Windows и опубликованных объектов фиксируется ниже.

Откат: адресный исходник features.py before add instrument design и только собственные hunks; SQLite не заменять. Приватные базы/настройки не публиковать. CORE, CandlePilot, стратегия, риск, позиции и прежний источник Search/identity resolver не менялись. Остаются выбранные окна новостей и рисования; премаркет/экономический календарь требуют отдельного фактического источника.
