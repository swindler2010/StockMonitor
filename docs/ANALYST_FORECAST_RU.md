# Прогноз аналитиков для акций

Новая вкладка «Прогноз аналитиков» и отдельное большое окно воспроизводят структуру выбранного образца: двухлетняя история, диапазон минимальной/средней/максимальной цели на 12 месяцев, шкала рекомендаций и последние решения аналитических компаний. Оформление использует тему и язык СМ (ru/de/en).

Данные: существующий Yahoo Finance/yfinance. Это другой источник, поэтому значения и набор аналитиков могут отличаться от TradingView. Исходная валюта показана явно; финансовая валюта отчётности не подставляется вместо валюты цены. В истории решений неподтверждённая валюта цели отмечена отдельно. Имена аналитиков, которых источник не предоставил, не придумываются.

Одна общая реализация действует для всех 106 акций текущего списка. У 75 уже настроен профиль, у 31 его не было. Для последних поиск выполняется по ISIN через существующий market.resolve_symbol с точной проверкой ISIN/тикера/площадки/валюты, максимум двух кандидатов за попытку. Торговая конфигурация акции не меняется. Отсутствие покрытия аналитиками или доказанной привязки остаётся явным. Полнота данных поставщика для всех 106 этим этапом не сертифицируется.

Загрузка работает в существующем Dispatcher, вне Tk. Сначала отображается сохранённый результат, затем выполняется допустимое обновление. Кеш сохраняется отдельно analyst_forecast:<ISIN>, срок актуальности 24 часа, минимальный интервал повтора 15 минут. Явная кнопка обновления может обновить свежий дневной кеш после этого интервала. Повторный показ карточки не обновляет её дату. При частичном отказе сохраняются исходные даты отдельных разделов; история другой валюты/тикера или другого снимка не смешивается с новой целью. Изменённый выбор и опоздавший ответ проверяются перед показом. Новых потоков, торговых приказов и разрешений нет.

Проверка: 29 уникальных адресных сценариев PASS, SOURCE_CHANGES=0; 25 новых + 4 затронутых проверки прежней очереди/данных. Включены 53/200 разных профилей, несовпадающий ISIN/тикер/валюта, старый кеш, ограничение повторов, отсутствие и действительный ноль рекомендаций, частичный отказ, просроченное подтверждение профиля, изменение выбора и сохранение масштаба.

Живой источник: Oracle ORCL — 501 точка 1D, цели в USD, 42 рекомендации, 100 решений; Moderna без готового профиля — подтверждён MRNA по US60770K1079, 501 точка и доступный прогноз. Это публичные вспомогательные данные, не изменения свечей или торгового допуска. Порядок ошибок прежней задачи CandlePilot этим этапом не менялся: прямых исправлений свечей Work 0.

В исходном объёме новой функции экрана прогноза не было у 106/106 акций. Код общего экрана подготовлен для 106/106; приёмка в рабочем TEST пока ожидает согласованного общего запуска. Проверка источника не означает проверку всех 106 поставщиком. Одна обнаруженная ошибка новой компоновки устранена: внутренние прокручиваемые контейнеры не используют растягиваемый картинкой стиль рамки. Общие main_screen/performance/диагностики другого Work не менялись.

Откат: адресный Analyst forecast addressed before.zip/patch в СМ-Архив; обратные фрагменты workspace_pages и один ключ ui_messages, удалить только новые модули/тест. Не заменять целиком поздние общие файлы, не менять SQLite, счёт, настройки стратегий и позиции.

Статус: READY_FOR_SHARED_RELOAD. Фактическая Windows-проверка рабочего TEST будет добавлена после согласованной загрузки; готовность runtime пока не заявлена.
