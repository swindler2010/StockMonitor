# Выбранный дизайн списка акций

21.11.2026 — Stock Monitor 0.16 TEST. Следующий этап после главного экрана и индикаторов.

Новый список: верхняя навигация, заголовок, реальные сводные счётчики, поиск по имени/тикеру/ISIN, фильтры статуса/ТФ/площадки, сортировка, таблица с логотипами/избранным/тикером/площадкой/интервалами/состоянием/датой, правая карточка выбранной акции и нижние действия. Приоритет по умолчанию — прежний stock_order. Иные сортировки/фильтры меняют только показ. Выбор использует прежние symbol.set/refresh_chart; избранное — существующий main_screen.toggle_favorite.

Площадки и ТФ проецируются из уже прочитанных compact metadata в штатной read-only задаче stock_order. Нет нового SQL, анализа свечей, загрузчика, очереди, вычисления READY или изменения rank/допуска. STALE сам по себе не превращается в CURRENT. Из current candidates берутся только ранее проверенные интервалы, неподтверждённые поля остаются «—».

Счётчик «Готовы» относится к группам анализа, не является обещанием исполнения сделки. WAIT и причины устаревшей цены сохранены. Числа и пример 92% качества с изображения не подставлены. Точный численный процент DQ не читается этим представлением; данные отдельной диагностики не выдумываются. Новые CSV/Yahoo-импорты, отсутствовавшие в прежнем окне, под видом дизайна не добавлены. Сохранены действовавшие выбор, порядок и логотипы; добавлена кнопка прежнего добавления инструмента.

Три целевых сценария PASS: фильтр/выбор без изменения universe и автоматической сделки; новый/удалённый инструмент и отложенный callback закрытого окна; неизвестное состояние не считается готовым, provenance и доступные ТФ берутся только из действующих метаданных. Первый реальный запуск просмотрен; увеличены плотность/шрифты строк и пропорции карточек. Финальная Windows-проверка и проверка опубликованных объектов записываются ниже.

Торговая стратегия, PAPER, существующие позиции, риск, CORE, DQ и CandlePilot не менялись. Адресный откат — logos016.py/watchlist_order.py before watchlist design и собственные hunks, без замены SQLite или чужих изменений. Приватные данные в публикацию не включаются.

Следующие выбранные окна: поиск/добавление, новости и рисование. Премаркет/экономический календарь всё ещё требуют фактического подключённого источника.
