# STOCK MONITOR / CANDLEPILOT — ЕДИНЫЙ MASTER-РЕЕСТР

**Снимок:** 2026-11-11 · **Репозиторий:** `swindler2010/StockMonitor` · **Версия:** 0.16 TEST (0.15 Store не трогать)

> **Статус документа:** первый консолидированный реестр, а не приёмка кода. Старая историческая оценка PASS/PARTIAL/OPEN не равна сегодняшнему E2E PASS. Существующие Issues сохраняются как исходный архив и НЕ удалены. В конце есть индекс всех найденных комментариев. Пока старые Issues не перенесены буквально, их удалять нельзя.

## Правила реестра
1. **Единая каноническая задача** имеет ID группы G; исходные номера 1–62, N, D, History/FIX, T и CP — сохраняемые алиасы и независимые подусловия, не отдельные параллельные поручения.
2. Дубли объединяются на уровне *объёма работы*, но distinct проверки, баги, решения владельца и acceptance не удаляются.
3. DONE только при доказанных исходниках + targeted tests + реальном Windows TEST/Bridge E2E, если требуется. Отдельный unit PASS не закрывает задачу.
4. Рабочие Apple/NVIDIA имеют приоритет, Amazon — следующий; не готовить остальные 57 для торговли массово.
5. Только настоящие GETTEX/EUR OHLCV с provenance, без синтетических баров/подмены площадки. TradingView — доверенный ориентир владельца, а не подтверждение конкретной сделки GETTEX.
6. Не начинать платные API, не переписывать готовые движки, не менять Store 0.15, реальные деньги и торговые guards без отдельного разрешения.
7. Каждая будущая правка обязана ссылаться на **один G-ID**, остальные алиасы направляются сюда. Work1/Work2 не изменяют общие файлы/SQLite одновременно.
