# V1 «Долгосрок» с Scalable Capital — задача №26

Сборка для проверки. Команда «Портфель» открывает отдельное окно «V1 · Scalable Capital».
Установите в среду Stock Monitor зависимости из `requirements-v1-scalable.txt`.
Откройте окно и нажмите «Подключить SC» для отдельного браузерного входа
в официальный Scalable MCP. V1 вызывает только чтение списка портфелей, позиций,
оценки портфеля и доступных средств без кредита. Токены хранятся в хранилище
учётных данных Windows, последний снимок — в каталоге данных приложения.
Открытое окно повторяет синхронизацию каждые 15 минут. При ошибке отображается
состояние подключения, а предыдущий снимок помечается как устаревший.

Оценка позиции в EUR опирается на количество и цену SC. Веса и сценарии используют
общую оценку SC как знаменатель. Для оценки входа используется медианный годовой
свободный денежный поток за три года и последняя доступная годовая численность
обыкновенных акций. Примерные сценарные доходности денежного потока 10%, 7,5% и
5% заданы для исследования. Курсы — справочные курсы ЕЦБ. Неполные данные
ограничивают применимость модели. Для кандидатов нужна свежая цена из штатного
GETTEX-источника. По новостям отображаются оригинал, ссылка и показатель, на
который следует обратить внимание. Сценарии показывают расчёт по покрытым
позициям. Валюта отчётности служит приближением для долларовой экспозиции.

Проверены 17 модульных сценариев, включая целостность снимка, оценку EUR,
докупку, продажу в симуляторе, стресс-тест и блокировку инструментов записи.
Live-чтение в подключённом чате подтвердило доступ к реальным данным; вход из
Windows-сборки, обновление после перезапуска и сквозная приёмка остаются
открыты. Также открыты историческая проверка с публикациями на дату сигнала, полный
фундаментальный и новостной охват и проверка модели 1W/1D.

Для отката вернуть прежний обработчик окна и откатить коммиты ветки. Существующие журналы
PAPER остаются в прежних хранилищах. V1 исключена из автоматической очереди
PAPER; перед приёмкой нужно проверить, что V2/V4/V5 продолжают работать.


## Дополнение 24.11.2026 — средняя цена, P&L и новости

СМ читает страницы исполненных операций SC, сверяет открытые лоты с
количеством по позиции и показывает расчётную среднюю цену и нереализованный
P&L в EUR. FIFO рассчитывается по суммам и датам событий в истории.
Для переводов это оценка: первоначальная дата покупки может отличаться от
даты записи перевода. Неоднозначная отмена, несовпадение количества или
отсутствие стоимости открытого лота дают отдельный статус без подстановки нуля.
V1 хранит расчётные показатели, не сохраняет полный журнал операций в снимке.

При существенной новости из ленты эмитента V1 переводит вывод в режим
пересмотра и показывает прежний статус. Материалы СМИ отображаются со ссылкой
и пометкой проверки, срабатывание зависит от покрытия лент в СМ.
Подтверждены адресные проверки переноса лотов, страниц истории и влияния
новости. Реальный коннектор чата подтвердил сверку количества по всем
доступным позициям, данные счёта не коммитились. Первичная проверка и
повторный вход из Windows-сборки остаются частью приёмки #26.


## Интерфейс V1 — отдельное окно Scalable Capital

Команда «Портфель» в меню «Вид» и в списке акций открывает V1.
По умолчанию видны только позиции SC, стоимость портфеля, средства без
кредита и рекомендации. Средняя цена, вес, обоснование и новости доступны
при выборе позиции. Кандидаты и сценарии доступны через «Анализ».
«Локальные позиции / Демо» открываются отдельно через меню «Торговля».
В демосчёте прежнее название V1 заменено на «Архив V1».

Проверено на Windows/Tk: 4 сценария окна и 17 тестов расчётов. Приёмка
в рабочей сборке с реальным входом SC остаётся открытой.
