# Stock Monitor 0.16 TEST

Исходники действующей Windows TEST-версии: свечные графики, CandlePilot, DQ/CORE,
Bridge/MCP и виртуальная PAPER-торговля. Это тестовая версия, не выпуск Microsoft Store.
Наличие кода не означает готовность всех рыночных данных или разрешение на исполнение.

## Запуск отдельной копии

Нужны Windows, официальный Python 3.11+ с Tk и зависимости из requirements.txt.
Проверенная рабочая среда и результаты тестов перечислены в [отчёте синхронизации](docs/CHANGELOG_2026-10-23_to_current.md).

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item stock_monitor/config.example.json stock_monitor/config.json
.\.venv\Scripts\python.exe stock_monitor/app.py
```

Копировать example следует только при отсутствии собственного config.json.
Запуск из исходников создаёт отдельный `test-data` рядом со `stock_monitor`.
Он не импортирует данные установленной Store-версии. Не направляйте тесты в рабочие базы.
Пример содержит публичные идентификаторы двух акций, но не архив, владельческие разрешения,
учётные данные, позиции или разрешение автоматической торговли. Листинг проверяется штатным механизмом.
EUR-источники разных площадок сохраняются отдельно.

Личный `Open_Test_016.cmd`, каталоги окружения, базы, история котировок и профили туннеля
намеренно не опубликованы. Не используйте старые скрипты миграции вместо указанного запуска.

## Состав

- `stock_monitor/`: Windows UI, SQLite, история, источники, DQ, аналитика и очередь.
- `paper_hourly.py` внутри пакета: действующая V1; её правила не менялись при синхронизации.
- `paper_strategy_v2.py`, `paper_strategy_shadow.py`, `paper_strategy_replay.py`:
  эксперимент V2 и два независимых теневых портфеля; исполнение в основной счёт отсутствует.
- `test_*.py`: существующие тесты; часть исторических сценариев требует непубликуемых fixtures.
- [Bridge/MCP](docs/BRIDGE_MCP_CAPABILITIES_RU.md): команды, ограничения и подключение.
- [Проверки и откат](docs/VALIDATION_AND_ROLLBACK_RU.md).

Не запускайте без разбора `unittest discover`: в историческом наборе есть GUI,
провайдерские и архивные сценарии. Используйте документированный изолированный regression.
Новые подписки, права поставщиков и подключения на целевой машине настраиваются отдельно.
